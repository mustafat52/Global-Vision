# Global Vision website, version 2

Open `index.html` in a browser, or upload the folder to any static host. Keep `data.js` and `assets/` next to it.

## What is new
- Home page is a machine finder: set hole diameter and plate thickness, and it draws the plate (plan and section) and lists matching drills, the Karnasch cutter and depth, and Nitto punches.
- Brand pages are schedule lists with group filters. Brand index is typographic.
- Catalogue is native: five sections, item lists, comparison tables for magnetic drills and Nitto punches, and the original pages as zoomable images. The PDF is only a download.
- Enquiry list sends one WhatsApp or email request for several products.

## Before launch
1. Product images and logos load from gvtools.net. Save them locally and change `IMG` in `data.js`.
2. Finder capacities come from the listed cutter capacities in `MACH` (index.html). Confirm with the client. Punch limits come from the Nitto catalogue table.
3. Confirm: Magtron model names, Soyer BMK vs BMH, Unibor A100 vs A100S, Hitachi items, permission to show the 15 "Also supplied" brands.
4. Comparison tables were read from the printed catalogue. Verify the numbers.
5. Add full spec tables from the old product pages.
